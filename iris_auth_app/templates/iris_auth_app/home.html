How it works

  1. Choose an account or create a test account.
  2. Allow the browser to access the camera.
  3. Capture an eye image.
  4. The server checks the iris template before granting access.
Secure by design

Access decisions are made on the server, not trusted to the browser.

Minimal retention

Only the required template data and metadata are stored for verification.
